# AgenticCommands

Personal suite of custom developer commands and background extensions.

### 🛠️ Extensions
* **[PromptPatcher](https://github.com/Amaan12/PromptPatcher)** (`Alt + V`) — Global daemon that batch-fixes typos, grammar, and motor slips in-place in ~1.5s.

### ⌨️ Commands
* **Short Mode** (`/short`) — Enforces direct 1–3 sentence responses with zero fluff.
* **[SwarmLock](https://github.com/Amaan12/SwarmLock)** (`/swarmlock`) — Multi-agent file locking coordinator to prevent concurrent edit conflicts.
* **Bank Txn Sync** (`/sync-bank-txns`) — Parses bank transaction alerts from Gmail into Google Sheets.
